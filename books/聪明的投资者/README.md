# 《聪明的投资者》逐章伴读

本项目使用格雷厄姆 1973 年修订英文正文与 Jason Zweig 2003 年评注。按书序逐单元制作英文原文、忠实核对译文、易读版和独立伴读；每轮审核后再继续。序言和导论先行，随后是第 1—20 章。格雷厄姆、Zweig 与巴菲特的文字分别署名。
