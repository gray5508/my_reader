# 《估值原理》伴读入口

书源是用户提供的周洛华中文 EPUB，版权页为 2022 年 3 月第 1 版。阅读时先打开[全书索引](chapters/ch00/001_全书索引.md)：五个“论”的导言与 21 篇专题正文共 26 个单元，每篇都有小结和 EPUB 位置。

第 01—26 单元均已逐章完成伴读、易读版和 EPUB 原文版，并核对、同步阅读器。从索引选择任一篇，即可打开该篇的三个版本。打开项目根目录的[离线阅读器](../../打开阅读器.html)，在书架选择《估值原理》也可阅读。

这里的“伴读”解释作者怎样论证、哪里需要谨慎读；“易读版”用白话重述难点；“原文版”仅转排 EPUB。书中的资产和政策判断属于作者写作时期的观点，不直接转为今天的建议。

继续阅读时可直接指定单元或问题。新会话先看[本书规则](00_阅读规则.md)、[书源位置](sources/README.md)和[当前进度](state/当前进度.json)，再重读相关 EPUB 正文。用户实际读到哪里另行确认，不由助手制作进度推断。
