# 估值时限论

来源：`OEBPS/Text/part21.xhtml`。按用户提供的 EPUB 顺序转排；原书文字和疑似转制错误原样保留。

时间有三种表现形式：有限的生命、有成本的资金和有风险的机会。

当机会无风险、资金无成本时，生命就无限静止，个体不会进取，社会也不会繁荣。印钞票不是为改革赢得时间，而是为“不改革”赢得时间。

1

请想象你来到了美国大学棒球联赛的选秀现场。选秀赛的结果不仅将影响某些名牌大学的录取名额,还将同时决定被录取新秀的年度奖学金。因此,竞争是非常激烈的。但是,某些美国大学在“政治正确”的无形压力下有意识地提高有色人种的录取比例。为此,他们不得不打破某些天经地义的规则。当然,还是美国谚语说得好,“Rules are set to be broken”(我们制定规则就是为了打破它)。你正好听到了一场与之相关的私下交谈。

主裁:“什么?又是一个坏球?他怎么搞的?不是说好了让他喂球的吗?通知接球手身后的边线裁判,刚才这个算好球。”

教练:“里奇,大家都这么帮你,你怎么还不努力呢?你可是60年来第一个进入选秀赛的印第安酋土著球员啊!”

里奇:“我不想干了,你们只是要一个土著投球手来装门面,我简直成了你们装点派对用的圣诞老人。我不是你们的装修材料。我不玩了,因为你们根本没有打算带我玩。”

教练:“主裁,比赛能不能暂停?投球手的情绪有些波动,我去安慰他几句。”

主裁:“没问题。你快去安慰他。刚才那一节比赛不算,我会安排组委会重新计时。”

主裁不断打破规定,延长比赛时间的结果就是得到一支平庸的球队,以及充满抱怨的投球手。家长不断塞钱给一个赌徒的结果就是既害了孩子,又害了家人。无条件、无原则溺爱的结果就是得到一个很调皮的小孩。无限制、无节操地印钞的结果就是得到一堆懒散的国有企业。好心办坏事违反了大自然的法则,这条命运法则高于人类的一切智慧、法律和同情心,我们最终都将由它来审判。

时间有限,这是一切责任心的来源。一旦时间无限,那就会出现无人任责的情况。
