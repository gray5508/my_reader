# 本书阅读规则

1. 这是一部 2022 年出版的中文论述作品。目录中的五个“论”各有正文，和其后的 21 篇专题一起构成 26 个阅读单元。全书索引及各章小结是导航，不能替代逐章阅读。
2. 每次只处理一个阅读单元：从 [书源索引](sources/README.md) 定位对应 XHTML，重新读全文；如有图像、注释、数字或提取异常，核对 EPUB 内原文件。写 `001_伴读.md`、`002_易读版.md`，并转排 `003_原文版.md`。完成本章核对后更新助手进度与书架。
3. 伴读以论证路线和难点为主，不把作者的强烈修辞当成证据。将作者的观察、引述、类比、推测和我补充的解释分开；易读版用浅白中文重述机制，自拟例子标明“伴读辅助｜我补充”。本书不需要翻译版。
4. 书中有写作于 2020—2021 年的调查与市场例子。标注原始时间；历史事实、政策、市场数据如需书外延伸，先查证来源。作者提出的公式和有关房价、比特币、央行、强式有效市场等判断应按其论证边界理解，不当作现时投资建议。
5. 原文版只做排版与图片提取，不删段，不在正文内混入解说。EPUB 自身的错字、日期、数字和脚注瑕疵保留；必要时另写勘误提示，不默默改写。
6. 阅读器从 `chapters/chXX/` 中的 Markdown 自动收录内容。`000_索引小结.md` 是待伴读章节的导航页，不代表已完成。每章完成后在 `reader-web` 运行 `npm run sync:reader`，检查该章三个阅读版本。只记助手已处理章数；用户已读状态须用户亲自确认。
