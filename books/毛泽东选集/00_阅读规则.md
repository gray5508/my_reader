# 阅读规则

现有 32 篇分为五个主题组，可按 [README](README.md) 选择一组阅读；组内沿 EPUB 顺序排列。每篇先看 `001_伴读.md` 的背景和阅读问题，再读 `002_易读版.md` 抓论证路线，最后读 `003_原文版.md`。易读版压缩重复论辩，不是原文的替代；原文版保留 EPUB 的正文、原注和顺序。对有争议的时间、事件和文本来源，回到 EPUB 与外部史料核对。

`全篇索引.md` 覆盖 387 篇，内容线索由原文开头及章节标题提取，适合检索和选篇，不能据此判断一篇全文的立场或细节。每次用户指定未开放篇目时，先重读全文再写伴读，并更新 `目录.json` 的 `selected`、进度文件和阅读器数据。

伴读应回答：作者面对的具体问题是什么；写作前可确认的经历或事件是什么；他如何取得材料、展开论证；哪些段落要慢读、哪些可先略读；带着什么问题检验其判断；后续历史对当时主张提供了什么支持或反证。背景须注明出处，无法确认的个人经历不要补写。政治分类、价值判断与历史结果分开叙述。

逐篇复核时，先对照 EPUB 全文和注释，逐项检查伴读是否准确交代写作时点、问题、证据、推论与阅读定位；再检查易读版是否覆盖主要论证而没有把条件、反对意见或作者的历史预期改成确定事实。修改后核对原文版无漏段、错序，并在 `state/第二轮逐篇复核.md` 记下本篇改动和未解决问题。只在本篇完成后移向下一篇；跨会话按项目通用规则交接，不依赖上个会话的压缩摘要。

阅读器章节顺序沿 EPUB；灰色篇目不可选。按主题组筛选后，目录与上下篇按钮都只在该组已开放篇目间移动；选“全部篇目”可看完整目录。新增内容后运行 `reader-web/` 中的 `npm run sync:reader`；改动阅读器外壳后运行 `npm run build:offline`。用户阅读位置由浏览器保存，不能据此推定用户已读。
