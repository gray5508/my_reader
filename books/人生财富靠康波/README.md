# 《人生财富靠康波》原文伴读

你直接读 [EPUB 原文](../../ebook/人生财富靠康波.epub)。我已逐篇读过正文并留下 18 篇章节小结和 [定位索引](sources/README.md)；它们是导航，不替代原文。你说“伴读第 7 篇”或“我读到美元破百”，我会再打开对应原文，挑这一篇最值得解释的内容来讲，不套固定问答模板。

这本书由不同时期的研究报告、演讲、访谈编成。推荐序二从 2024 年回看，正文多写于 2005—2016 年。阅读时先看篇首日期：其中的年份、资产判断和“未来”都属于写作时的预测。书中有大量图表；若某个判断依赖曲线、统计表或公式，伴读时回到 EPUB 的原图核对。

建议从第 1 篇认识作者说的“康波”和价格波动，再读第 7 篇建立三周期与主导产业的概念；第 11—13 篇是商品、房地产、黄金三个较完整的专题。第 2—6、8—10 篇可以顺读其研究方法与历史情境；第 14—18 篇听作者怎样向不同听众解释和运用框架。这个顺序只是导航，可以从你正在读的任何一篇开始。
