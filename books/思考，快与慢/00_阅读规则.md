# 《思考，快与慢》阅读规则

英文 EPUB 是翻译依据。中文 MOBI 仅在可读取且需要时核对术语和疑难处；不把其措辞反译为英文。EPUB 的 href、抽取块和 offset 是源位置，不是纸书页码。

本书按认知心理学与行为决策论述阅读。每章保留同一源片段的 `忠实核对版` 与 `中文语境易读版`，放在 `chapters/chXX/`，共用三位批次号。忠实版保留论证、实验步骤、数字、限定词和例子；易读版以自然中文重述，但不删实验条件或把概率性倾向说成绝对规律。作者论述、实验观察、作者解释和伴读补充应分清。

“系统1”“系统2”是书中解释心智活动的命名，翻译时不写成两个真实的人或固定脑区。遇到需要读者先完成的题目，先呈现题目，再按原文顺序呈现提示和答案。图、表、公式、脚注须核对 EPUB 的原始 XHTML；抽取失败处说明位置，不凭记忆补文。

通常每次处理一个适合交互的小节或片段；用户明确要求整章或多章时，仍按连贯片段分批保存，再按指定范围依次完成。已交付与用户已阅读分别记录。用户已指定并授权前五章顺序翻译；该路线的英文 EPUB 全章译文现已交付，用户是否读完尚未确认。章前导航只帮助定位，不能代替实际原文。

章节 Markdown 是译文真源。日常新译只写该书章节文件、入口和进度，随后在 `reader-web/` 执行 `npm run sync:reader`，验证阅读器数据；不为新增译文改页面代码。个人观点仅记录用户明确表达，不上传提取缓存。
