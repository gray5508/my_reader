# 《思考，快与慢》术语表

| 英文 | 本书暂定译法 | 提醒 |
|---|---|---|
| System 1 / System 2 | 系统1／系统2 | 作者的解释性命名，不当作独立人格或脑区。 |
| fast / slow thinking | 快思考／慢思考 | 依具体语境调整语序，不机械代换。 |
| automatic / effortful | 自动的／需要付出心力的 | 保留程度与条件。 |
| attention / attention budget | 注意力／注意力预算 | “预算”是作者解释资源有限的比喻。 |
| cognitive illusion | 认知错觉 | 与视觉错觉类比，不等于临床诊断。 |
| Müller-Lyer illusion | 缪勒－莱尔错觉 | 第1章图3的线长错觉。 |
| working memory | 工作记忆 | 第1章用于解释简短名称为何便于思考。 |
| flow | 心流 | 第3章；区分任务投入与维持注意力的自制。 |
| ego depletion | 自我耗竭 | 第3章作者引用的研究术语；不写成个人诊断。 |
| priming / priming effect | 启动／启动效应 | 第4章；保留具体实验线索和结果。 |
| associative memory | 联想记忆 | 第4章；观念网络，不限于有意识的顺序联想。 |
| cognitive ease / strain | 认知放松／认知吃力 | 第5章；可由多种原因造成，不能等同真伪。 |
| mere exposure effect | 单纯曝光效应 | 第5章；重复接触与好感的研究术语。 |
| Remote Association Test | 远距联想测验 | 第5章；英文词组及构词关系是题目材料。 |

随实际原文增量维护；未读章节的术语不预填。
