## 一眼看到坏盘子，就觉得整套不值钱

许在一家通常卖**30—60美元**餐具的商店设计了三组估价：一组同时看A、B两套；另外两组分别只看其中一套。先看货品，假定同类餐具品质相同：

|  | A套：40件 | B套：24件 |
| --- | --- | --- |
| 正餐盘 | 8件完好 | 8件完好 |
| 汤／沙拉碗 | 8件完好 | 8件完好 |
| 甜点盘 | 8件完好 | 8件完好 |
| 杯子 | 8件，2件破损 | 无 |
| 杯碟 | 8件，7件破损 | 无 |

A把B的24件全包进来了，此外还有**7件好的、9件坏的**。两套摆在一起时，人们给A约**32美元**，B约**30美元**，大小关系合乎“多了完好餐具就更值钱”。但只让各人看一套，B的估价变为**33美元**，A却只有**23美元**。看到A的人受破损品影响，把整套的平均品质看低。研究者称这种反转为“少即是多”：从A移去16件，连7件好餐具一起移去，整套的评价反而变高。

李斯特在真实棒球卡拍卖里也得到类似结果：十张高价值卡组成一套，另一套在同样十张之外加三张中等价值卡。同时看两套，大套装估价更高；各人只看一套，大套装反而更低。额外三张卡仍有正价值，按加总的价值逻辑不该让套装贬值。

琳达题也可这样想：**所有银行柜员**可分成“积极参与女权运动的柜员”和“没有积极参与女权运动的柜员”，两类人数或概率相加才是全部柜员。系统1却容易只看每一类给人的平均印象，觉得“女权主义柜员”更像琳达，于是“所有柜员”似乎还不如这一小类可能。餐具同时摆出来，多与少的关系较显眼；琳达题即使同时看两项，故事的贴合感仍可能压过集合逻辑。
