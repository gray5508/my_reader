## 少即是多：有时连同时比较也不够

芝加哥大学的克里斯托弗·许让人给一家本地商店清仓销售的餐具套装定价；店里这类餐具通常卖**30—60美元**。实验有三组：一组看到下面两套，可作**同时评价**；另两组各只看到其中一套，是**单独评价**。前者同一人比较两套，是组内设计；后者由不同人分别评价，是组间设计。原 XHTML 表格如下：

| 餐具 | A套：40件 | B套：24件 |
| --- | --- | --- |
| 正餐盘 | 8件，均完好 | 8件，均完好 |
| 汤／沙拉碗 | 8件，均完好 | 8件，均完好 |
| 甜点盘 | 8件，均完好 | 8件，均完好 |
| 杯子 | 8件，其中2件破损 | 无 |
| 杯碟 | 8件，其中7件破损 | 无 |

若假定两套里同类餐具品质相同，哪套更值钱？A包含B的全部餐具，另有**7件完好的餐具**，所以它应更值钱。实际在同时评价组，参与者愿付A套**32美元**、B套**30美元**，A略高。

单独评价时，结果却倒过来：B套为**33美元**，A套为**23美元**。作者解释，套装会被规范与原型代表；人一看便觉得A套“平均每件”的价值低很多，因为没人想为破损品付钱。若平均质量主导整体评价，B更受重视就不奇怪。许称这种模式为**少即是多**：从A中拿走16件，其中7件还是完好的，整体估值反而提高。

实验经济学家约翰·李斯特在真实的棒球卡市场复现了这种结果。他拍卖十张高价值球星卡组成的套装，也拍卖同样十张再加三张中等价值卡的套装。与餐具实验一样，同时评价时，大套装比小套装值钱；单独评价时，大套装反倒估值更低。从经济理论看，这令人不安：餐具套装或球星卡集的经济价值是近似**加总量**，添入一件有正价值的东西只能增加价值。

琳达题与餐具题有相同结构。概率也像经济价值一样可以按互斥部分相加：

> P（琳达是银行柜员）＝P（琳达是积极参与女权运动的银行柜员）＋P（琳达是未积极参与女权运动的银行柜员）。

这也解释琳达题单独评价时的“少即是多”：系统1按印象**取平均**，而没有把两类柜员**相加**；把不符合人物印象的非女权主义银行柜员从心里剔除后，主观概率反而上升。不过概率的可加性不如金钱价值那样显眼。因此，同时评价消除了许的餐具实验中的错误，却未完全消除琳达题的错误。
