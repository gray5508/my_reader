# 第27章 禀赋效应｜003｜中文语境易读版

研究者先用**可换现金的代币**试市场：每个人兑换代币能拿到的钱不同，代币便会从低估值者流向高估值者。随机把代币给一半人时，理论预计约一半代币换手。实验的成交数也通常接近预测。代币没有收藏或使用价值，持有它是为了换钱。

再把代币换成可能想自己用的**马克杯**。当时杯子约值6美元，随机发给一半参与者。拥有杯子的人报卖价，没杯子的人拿自己的钱报买价。结果卖家平均要价约为买家平均出价的两倍，实际预计成交数不足理论预期的一半。杯子既能交易，也能自用，“放弃已有的”便进入了选择。

最能看清这一点的是第三组：**选择者**。他们可以拿杯，也可以拿钱，报一个与杯子同样吸引自己的金额。三组结果是：

| 角色 | 金额 |
| --- | ---: |
| 已有杯、可卖的卖家 | 7.12美元 |
| 可在杯与钱之间选的选择者 | 3.12美元 |
| 用自己的钱买杯的买家 | 2.87美元 |

卖家与选择者最终都能“带杯走”或“带钱走”，只是卖家眼前已经拥有杯子。两组金额差距很大，因此把差距只归于最终得到什么，说不通；参照点与交出杯子的感受是作者的解释。买家和选择者金额接近，也支持“日常买东西时，预算内付款不总被当作一笔额外损失”的看法。

作者还把卖家对杯子的估价与风险选择中的损失厌恶比率作比较，两者都大致接近2:1；他援引价格研究说，涨价引起的需求减少可比同幅降价引起的增加更大。这是所引实验与市场研究的结果，不能用“所有人对任何东西都恰好两倍”去套。脑成像结果也只是补充观察。

最后一项更简洁的实验：两班人分别先拿到钢笔或瑞士巧克力，放在眼前一段时间，然后可以换另一种。约10%的人换，绝大多数保留起初拿到的礼物。关键不是两种礼物谁更好，而是**先拥有哪一种**。
