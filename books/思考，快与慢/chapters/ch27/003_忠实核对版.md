# 第27章 禀赋效应｜003｜忠实核对版

卡尼曼、塞勒和克内奇借用实验经济学家弗农·史密斯的市场方法：向部分参与者分配代币，实验结束时持币者可向研究者兑换现金。每个人的兑换额不同；同一枚代币对你值10美元、对我值20美元时，任何处于二者之间的成交价都可能让双方受益。参与者公开连续报买价或卖价，其他人公开回应，所有人能看到成交价。史密斯发现，兑换额低的人会把代币卖给估值高的人；最终代币流向最能从研究者处兑到钱的人，收敛价格与成交数量也符合标准理论。如果随机给一半参与者分配代币，理论预测约有**一半代币换手**。

他们先做数轮代币市场，成交数量通常很接近、有时恰好等于理论预测。代币仅为兑换实验现金而有价值，没有“拿来使用”的价值。随后改为带大学徽标的精美马克杯，预计参与者会想自己用。当时杯子约值**6美元**，作者说若按写作时点价格约为两倍。随机把杯子给一半人；卖家把杯子放在面前，买家可看邻座杯子，双方报愿交易的价格，买家须用自己的钱付款。结果卖家平均要价约为买家平均出价的**两倍**，预计成交数量还不到标准理论预测的一半。这次，为使用而持有的物品没有像代币那样顺畅交换。

研究者用相近程序反复做实验，得到类似结果。作者最喜欢的一种变体增设第三组**选择者**：买家须用自己的钱买杯；选择者则可免费选杯或一笔钱，并报出与杯子同样吸引自己的钱数。原 XHTML 的报价表为：

| 角色 | 报价或等价金额 |
| --- | ---: |
| 卖家（Sellers） | 7.12美元 |
| 选择者（Choosers） | 3.12美元 |
| 买家（Buyers） | 2.87美元 |

卖家与选择者最终面对**相同的两个结局**：带走杯或带走钱；他们的差别是此刻卖家已有杯，选择者还没有。卖家较高的价格反映不愿放弃已拥有物的即时情绪。作者用婴儿紧抓玩具、被拿走时激动作类比，并把损失厌恶归于系统1的自动评价；这里的系统1是心理活动的解释标签，不是一个实体人物。

买家和选择者给出的金额很近，虽然前者真要掏钱，后者的杯子可免费获得。作者认为，这符合“买家没把为买杯而花的钱当成损失”的解释。他又援引脑成像研究：卖出平常用的物品会激活与厌恶、疼痛相关的脑区；买东西只有在价格被感到过高时才会出现类似活动；特别便宜的购买会伴随愉悦活动。这些是书中所引研究的关联观察，不能把脑区活动本身当作单个购买决定的证明。

卖家对杯子的估价略高于另两组的两倍。作者说，这与风险选择中约2:1的损失厌恶系数接近，若有同一得失价值函数作用于有风险与无风险决策，这种接近是可以预期的。他还说，多种经济情境曾出现约2:1，包括家庭对价格变化的反应：鸡蛋、橙汁或鱼降价时，人们一般多买，涨价时少买；但书中所述研究里，涨价相对参照价格造成的需求变化，幅度约为降价带来的变化的两倍。比率来自这些研究，不是适用于所有商品、地区或时期的常数。

另一项克内奇实验向两个班级的学生发礼物：一组拿昂贵钢笔，另一组拿瑞士巧克力，并把礼物放在面前直到实验结束。最后研究者展示另一种礼物，允许交换。只有约**10%**的人换；多数拿笔者留笔，拿巧克力者也留巧克力。随机先持有哪一种，显著影响了之后是否换手。
