# 第4章｜独立伴读

英文 EPUB `OEBPS/9781429969352_ch04.xhtml#p0001–p0039`，提取流 offset `0–23166`，39个文字块。原 XHTML 中的 `OEBPS/67.jpg` 是有内容的图4，已按原图保存并嵌入；`arr.jpg` 六次出现均为装饰箭头。本章无脚注。

先按原书顺序看“香蕉／呕吐”，停一两秒，再读作者怎样描述可能出现的画面、厌恶感、身体动作和因果故事。**题面只有两个词，并没有说香蕉导致呕吐。**重要的是心智可能自动把并列词语拼成一个连贯场景，同时让相关词和感受更容易浮现。作者称它为联想激活；“联想一致性”指词、记忆、情绪、表情和回避倾向相互支持，不等于故事本身真实。系统1在此仍是解释这种活动的标签，而非脑内的独立角色。

休谟归纳的相似、时空接近、因果关系，为作者提供了历史起点；现代网络比“一个有意识的念头接着另一个”复杂：一个观念可同时带出许多关联，大多数过程不进入意识。读 `EAT → SO_P` 与 `WASH → SO_P` 时，保留英文词形很重要。`SO_P` 可以补成 **SOUP** 或 **SOAP**，前面见到的词改变两种补全的相对容易程度。这个词语任务是本章最直接、最便于理解的启动例子。

从词语到行动，证据的跨度增大。巴奇的学生先排五词中的四词句，一组题目的一半带有老年线索，研究者再暗中计时他们走过走廊的速度。作者将较慢步行解释为观念运动效应；德国慢走实验、含铅笔评价漫画、点头或摇头听广播评论，都是其他任务和指标。它们共同展示作者想要的“双向连接”图景，却不能把其中任一结果扩展成“读到一个词就必然改变你的动作”。原文说读到老年段落的你起身倒水也会稍慢，是作者把实验推到读者身上的推断，不是他对当前读者的实测。

后半章把启动移到社会选择。亚利桑那州2000年投票站位置与学校经费提案支持率的关系，是地点与投票模式的观察；教室图片实验是另一个设计。金钱线索研究包含四词短语、大富翁纸币、钞票屏保，指标则有求助时间、帮助行为、捡铅笔数、椅子距离与独处偏好。**118厘米对80厘米**只属于摆椅子任务。作者由这些结果进一步发问文化中的金钱和领袖肖像如何塑造行为，其中独裁社会的画像一段是反问式推论，不能读成该章直接完成的实验。

图4值得打开仔细看。纵向列出第1到第10周，**第1周在最下方**；黑点为“眼睛周”，空心点为“花朵周”。横轴不是捐款人数，而是按消耗的每升牛奶折算的英镑投款。第1周约£0.70，即70便士；第2周约£0.15，即15便士。作者报告十周里眼睛周的平均投款近乎花朵周的三倍，并解释为象征性的“有人在看”促进按约定付钱。图里能直接看到每周投款差异，不能直接看到某个人心里是否觉得被监视，也不能凭这十周确定任何地方贴眼睛都有效。

最需要留心的是作者论证的力度。第28段说效应不一定大，100名选民中或许只有几位摇摆者改变决定；第29段又要求读者接受主要研究结论，并断言读者自己也会受相同线索影响。伴读应保留这两句之间的张力：**具体实验观察、作者对无意识机制的解释、推到每位读者身上的断言，是三层不同主张。**这一章既讲系统1怎样迅速形成有用的情境解释，也为后续章节讨论由这种连贯感造成的系统性错误铺路。
