# 《置身事内》阅读规则

1. 以用户提供的中文 EPUB 为唯一正文来源。目录的八个“第 X 章”是八个主要阅读单元；每章跨多个 XHTML，包含章引、各节、结语与“扩展阅读”（书中注释通常放在这里）。索引只列定位，不代替正式重读。
2. 每次只处理一章。按 `sources/README.md` 读取该章全部 XHTML；核对图像、注释、表格、数字和异常断句。写 `chapters/chXX/001_伴读.md`、`002_易读版.md`、`003_原文版.md`，逐章校对后更新助手进度并运行 `npm run sync:reader`。
3. 伴读讲清作者的机制、证据和适用范围；分开历史事实、案例、统计关联、因果解释与政策判断。易读版用简明中文重述，若自拟例子须标“伴读辅助｜我补充”。不生成翻译或“忠实翻译版”。
4. 原文版只转排 EPUB 的文字顺序、标题、注释及图片，不擅改原书数字、时点、措辞或疑似转制错误；问题写在伴读或源说明。书源无可靠纸书页码，用 XHTML 文件和段落开头定位。
5. 书中政策和经济数据有写作时点。若解释今天的政策、法律、统计或市场情况，先核实原始权威资料并标注日期；不把 2021 年的判断当作当下建议。
6. 文件、原文核对和阅读器三个入口均完成后，才把该章加入 `assistant_companioned_chapters`、`assistant_easy_read_chapters` 与 `assistant_original_export_chapters`。`user_read_chapters` 不随助手进度改变。
7. 前言、上下篇导言、结束语与参考文献均在书源索引保留定位；完成八章后再逐篇处理前言和结束语，扩展阅读已经随对应章覆盖。长任务在章末交接并新开同项目会话续做。
