# 《置身事内：中国政府与经济发展》伴读入口

这是兰小欢的中文原著。原书八章按章逐一制作伴读、易读版和 EPUB 原文版；每章含章引、各节、结语与扩展阅读。先看[全书索引](01_全书索引.md)、[章节与书源定位](sources/README.md)和[当前进度](state/当前进度.json)，再从已开放章节进入阅读器。索引和目录位置不代表章节已完成。

八章及前言、上下篇导言、结束语、参考文献的伴读、易读版和中文原文版均已开放；全部入口见[全书索引](01_全书索引.md)。也可双击项目根目录的[离线阅读器](../../打开阅读器.html)，在书架选择《置身事内》。

本书讨论的政策、数字和判断多有 2021 年前后的时点。伴读会区分作者的描述、解释和证据边界。用户读到哪里只依据用户确认，不以助手制作进度推断。
