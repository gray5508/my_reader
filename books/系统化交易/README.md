# 《系统化交易》伴读

英文原书：Robert Carver, *Systematic Trading: A Unique New Method for Designing Trading and Investing Systems*，2015 年首版。书源在 [本地 EPUB](../../ebook/Systematic%20Trading.epub)；具体章节定位及校验码见 [原书定位索引](sources/README.md)。

先看 [全书索引与每章小结](01_全书索引.md) 选择阅读路线。章节文件与书架同步进度见 [当前进度](state/当前进度.json)。已完成的章节提供伴读、中文易读版和英文原文版；易读版是讲解，不是全文译文。打开 [本地阅读器](../../打开阅读器.html)，在书架选择《系统化交易》。

本书重点是如何把交易决策拆成可检查的规则、风险预算、头寸和成本。案例与参数来自原书写作时期。学习方法时，先弄清变量和适用条件，再考虑它能否用于其他市场。尚未把任何章节记为你已读。
