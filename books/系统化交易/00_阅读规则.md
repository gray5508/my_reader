# 《系统化交易》阅读规则

- 主源是用户提供的英文 EPUB，位置见 `sources/README.md`。这是 Robert Carver 2015 年首版的写作语境；书中的案例日期、市场条件、交易平台及费用不能直接当作今天的数据或建议。
- 全书索引是导航：每章简短小结说明该章要解决什么问题。正式制作某章时，重新读取该章正文、图、表、公式和脚注；索引不能替代章内核对。一次完成一章，完成后再转下一章。
- 前言、引言及第 1–15 章交付 `001_伴读.md`、`002_易读版.md`、`003_原文版.md`、`004_忠实版.md`。伴读指出论证路线、阅读重点、图表和可能误读；易读版按问题、机制、例子、限制讲通核心内容，属于中文讲解而非全文翻译；原文版由 EPUB 转排英文；忠实版逐段译出正文、表格、图注和脚注。后记与附录 A 保留此前三版，本轮按用户决定不继续补做。
- 本书三类读者：半自动交易者、资产配置投资者、坚定的系统交易者。章节若只针对某一类，写明适用范围；不把期货、杠杆或英国 spread betting 示例默认迁移给所有读者。
- 公式核对变量、单位、年化与日化转换、币种、合约乘数和四舍五入。区分预测信号、波动率目标、单一标的头寸、组合权重、交易成本和执行；例子可以自拟，但须标“伴读辅助｜我补充”。回测结果、作者的经验判断和可复现的数学关系分别表述；不能把回测表现说成未来收益保证。
- 原书的正态分布、零自相关、相关性、波动率等假设，以及极端损失和流动性限制，若影响结论就写清。章节图表若图片文字不清楚，回到 EPUB 原文件检查，不猜图意。术语保持一致，并在首次出现时解释。
- 保留书源定位，使用 EPUB 文件路径与 `scripts/systematic_source.py` 的块号；块号不是印刷页码。用户只确认读过后才更新 `user_read_chapters`。助手进度在对应文件落盘并通过书架同步后更新。
- 每章 Markdown 在 `chapters/chXX/`；完成一章后在 `reader-web/` 执行 `npm run sync:reader`，检查书架版本与图片。会话接近准确可观测的上下文 60% 时，在完成当前章后新建本项目会话，交接书源、已完成章节、下一章及待核问题。占比不可见时保守提前交接，不声称已达某百分比。
