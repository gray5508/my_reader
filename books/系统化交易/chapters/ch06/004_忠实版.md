## 第六章 交易工具

**[ch06#0003]** 在考虑怎样交易之前，你需要先考虑要交易什么，也就是实际买进或卖出的工具。你大概会根据自己对不同市场的知识和熟悉程度，知道想交易哪些资产类别。

**[ch06#0004]** 不过，有些工具在系统化交易中应当完全避开。另一些工具具有某些特征，使它们不如其他替代品，或者迫使你以特定方式交易。最后，进入某个市场通常有不止一条路径：若要获得欧洲 Euro Stoxx 50 股票指数的敞口，可以购买成分股、交易期货、做点差投注、交易差价合约、购买被动指数基金或主动基金。哪一种最好？

### 必要条件 [ch06#0012–0027]

决定一种工具是否适合系统化交易时，有几点需要考虑。

#### 数据可得性

我希望能够交易英国国债期货，但我没有合适的数据许可，因此拿不到报价。没有价格及其他相关数据，就无法进行系统化交易。

你至少需要准确的每日价格信息。交易速度快或包含执行算法的全自动策略需要实时逐笔价格。基本面交易策略需要更多种类的数据。对于业余投资者，取得某些工具的数据（或许包括英国国债）的成本可能不划算。

#### 最小交易单位

还有一种我想交易却无法交易的期货，是日本政府债券（JGB）期货。当时一张合约价值约 1.5 亿日元，远超 100 万美元。若把它纳入我的组合，我希望持有的最大头寸是 0.1 张合约；显然，这做不到。很少有业余投资者能够交易这样的庞然大物。

股票的最小单位是一股，通常价值低于 1,000 美元，虽然伯克希尔·哈撒韦 A 类股票当时一股超过 100,000 美元。即便是价格较低的股票，少于 100 股的交易批量也可能不划算。

最小交易单位降低了可交易头寸的细分程度。你的头寸会变成二选一：要么全部持有，要么完全不持有（日本政府债券期货的情形则总是后者）。这是一个重要问题，我会在第十二章“速度与规模”再讨论。届时你会看到，这个问题也影响组合中能够持有的工具数量。

#### 价格为什么变动？

你知道债券、股票和其他工具的价格为什么上涨或下跌吗？“买家比卖家多”不是可接受的答案！我个人认为，理解市场靠什么运作很重要，无论是利率、经济新闻还是企业利润。如果你打算先从想法出发设计交易规则，这一点至关重要。

系统运行之后，了解市场动态也很重要，这样才能避免在市场机制失灵时遭遇令人不快的意外。在我重新起草本章时，瑞士政府刚刚取消了自 2011 年以来将本国货币固定在每欧元兑换 1.20 瑞郎的汇率钉住机制，结果瑞士法郎（CHF）对所有货币大幅升值。包括大型对冲基金和银行在内的数千名交易者处于亏损的一方，其中许多人采用系统化交易。

所幸，我没有交易 EUR/CHF 或 USD/CHF 外汇货币对。对我来说，尝试作出系统化预测似乎没有意义，因为我知道这个市场受央行干预控制，而不是受回测中通常推动价格的历史因素控制。持续了解市场情况，将帮助你避开类似的危险工具。

#### 标准差

我将瑞郎外汇头寸排除在系统化交易策略之外，还有一个原因：汇率钉住期间价格波动极低。原则上，我的框架既能处理收益率天然具有较低标准差的资产，也能处理风险很高的资产；它还能应对波动率随时间变化。

但是，风险极低的工具，例如被钉住的货币，应当排除。首先，当风险恢复正常水平时，很可能恢复得非常突然，并可能造成重大损失。其次，要达到给定的风险水平，这些头寸需要更高杠杆；它们最终突然爆发时，危险便会被放大。即便不用杠杆，它们也会限制整个交易系统能够达到的风险水平。⁷⁴ 最后，它们的交易成本往往也更高；你会在第十二章“速度与规模”看到这一点。

### 工具选择与交易风格 [ch06#0028–0044]

排除了不具备上述必要属性的工具、缩小可选范围之后，你需要决定更愿意交易余下的哪些工具。这些特征也会影响你如何交易选中的工具。

#### 交易多少种工具？

我希望组合中的工具尽可能多、尽可能分散，前提是不遇到最小交易单位的问题；日本政府债券期货就会使我遇到这个问题。你最多能纳入多少种工具，取决于最小交易单位、账户价值，以及你设定的风险目标（第九章“波动率目标设定”会讲到）。

在第十二章“速度与规模”，你会看到如何计算从哪里开始可能遇到工具最小交易单位的问题。然后你就能算出多大的组合才合理。

接着，在第四部分各个实例章节里，我会给出一些建议组合。这些组合在给定波动率目标和可用工具的条件下，力求尽可能分散。

#### 相关性

如果你已经持有苏格兰皇家银行（RBS）和巴克莱的股票，最不想再加进组合的，就是劳埃德这样另一家英国银行。一般来说，你应该希望持有或交易尽可能分散的组合，让资产之间的平均相关性低于其他可选方案。如果组合只能容纳有限数量的工具，选择相关性较低的工具就合理。

#### 成本

在其他方面完全相同的两种工具之间，你应该选择交易成本较低的一种。因此，如果条件允许，要获得英国股票指数敞口，就使用便宜的 FTSE 100 期货，而不要使用昂贵的点差投注。⁷⁵ 交易成本高的工具显然不太适合动态策略，尤其不适合交易较快的策略。

有时，你不得不交易一种昂贵的工具，因为它是取得某项资产敞口的唯一途径。这时应当放慢交易速度。不过，按你所采用的交易类型，成本仍有一个可接受的上限；因此，有些工具会完全不适用。交易成本如此重要，我会在第十二章“速度与规模”详细讨论。

#### 流动性

流动性与成本密切相关。流动性较差的工具，快速交易或大额交易的成本很可能更高。这对大型机构投资者和交易速度快的人尤其成问题。流动性并非恒定不变，在市场严重承压时会迅速减少；非交易所交易的“场外”（OTC）工具尤为如此，2008 年信用违约互换衍生品市场就是一例。

第十二章“速度与规模”也会解释：账户规模较大的人，比小投资者更需要充分理解成本和流动性。

#### 偏度

你是否应该避开组合中的负偏度，例如持有 VIX（美国股票波动率指数）期货空头所带来的负偏度？记得我在第二章“系统化交易规则”讨论过资产和交易规则的偏度。静态策略会继承底层工具的偏度，但动态策略的偏度还取决于交易规则的风格。因此，在负偏度资产上使用趋势跟踪这类正偏度规则，会减轻一部分危险。

如第九章“波动率目标设定”将要说明的，如果预期整个交易系统的收益呈负偏度，你就必须格外小心。具有极端负偏度的工具，在大部分时间里往往表现出很低的标准差；基于这一点，也应将其排除。

### 取得敞口的方式 [ch06#0045–0058]

最后，你需要选择通过哪条途径取得拟交易底层资产的敞口。

#### 交易所还是场外

你的工具是在交易所交易，例如通用电气股票和玉米期货，还是像外汇（FX）那样在场外（OTC）交易？同一底层资产常有不同交易方式，其中一些通过交易所，另一些通过场外。因此，针对 CHF/USD 汇率的点差投注属于场外交易，而芝加哥交易的同一汇率期货则属于交易所交易。

如果两者都可以选择，且其他条件相同，你该在交易所还是场外交易？在 2015 年 1 月瑞郎市场剧烈波动时，使用场外经纪商的交易者遇到各种困难，包括交易商不接订单、不显示报价、交易不被承认、成交价格事后被重新标记；极端情况下，经纪商清算还可能造成账户损失。

交易 CHF/USD 期货的人难以找到充足的流动性，但除此之外，市场照常运作。总的来说，若能选择，通常最好在交易所交易。

#### 现货还是衍生品

“现货”仅仅指你直接拥有底层资产，例如一股英国天然气公司的股票，或者通用电气发行的债券。另一种选择是持有基于某项资产的衍生品，如期货、差价合约或点差投注。⁷⁶ 衍生品的主要好处是能直接提供杠杆。没有杠杆，你可能难以达到波动率目标，从而降低可获得的回报。税务待遇也可能不同；例如在英国，点差投注被视为赌博，所以盈利免税，但亏损不能抵扣。

不同类型的衍生品可能有不同的交易成本、最小交易单位、流动性和市场接入方式。例如，FTSE 100 期货比对应的点差投注交易成本更低、流动性更好。它还有通过交易所交易的优势，而点差投注属于场外交易。但是，期货的最小交易单位更大，使规模较小的投资者无法使用。

#### 基金

交易 FTSE 100 的另一种办法是购买指数跟踪产品，例如交易所交易基金（ETF）。这类产品是集合基金：买入一份工具，就取得一篮子资产组合中的一份权益。除了 ETF，集合基金还包括美国共同基金、英国单位信托和投资信托。就系统化交易而言，你通常会关注指数跟踪产品这样的被动基金。它们持有一篮子资产，并按 FTSE 100 或 S&P 500 等指数的权重配置。

被动基金通常年费和最小交易单位都相对较低，但交易成本往往高于相应的衍生品。不过，在无法使用杠杆，或无法通过其他途径进入某个市场时，它们可能是有用的工具。

在某些情况下，你可能想使用主动基金，其中不同资产的权重由基金经理决定。如果没有合适的被动基金或衍生品，这样做可能合理；但主动基金费用更高，而且很难证明基金经理确有足以补偿费用的能力或超额收益（alpha）。

集合基金可能有每日重新估值、税务待遇、内部杠杆以及相对于资产净值的折价等特殊之处；使用前你应当充分理解这些特点。

### 工具选择总结 [ch06#0059–0083]

| 检查项 | 原书总结 |
|---|---|
| 数据可得性 | 系统化交易某种工具，至少需要每日价格数据。基本面策略还需要其他相关数据，例如使用股票价值规则时的市盈率。 |
| 最小交易单位 | 对小投资者而言，较大的最小交易单位可能是个问题。 |
| 理解是什么推动收益 | 不要脱离实际交易；至少要对推动收益的因素有所了解。如果存在不寻常的力量，就避开该工具。 |
| 收益的标准差 | 波动率不能极低。 |
| 交易多少种工具？ | 根据账户规模和每种工具的最小交易单位，你可以判断某个组合规模是否会带来问题。在这些约束下，应持有尽可能大的组合。 |
| 收益相关性 | 始终应尽力让组合中的资产尽可能分散。 |
| 成本 | 越便宜越好。昂贵的工具需要以更慢速度交易，也可能贵到完全不值得交易。 |
| 流动性 | 对规模较大、耐心较少的投资者，流动性至关重要。 |
| 收益偏度 | 强负偏度资产需要谨慎处理，不应在组合中占主导。使用合适的交易规则可以在一定程度上改善偏度。 |
| 交易场所 | 市场是通过交易所还是场外（OTC）进入？交易所较可取。 |
| 现货还是衍生品 | 应直接交易资产，还是交易基于其价值的衍生品？若选衍生品，又该选哪一种？ |
| 集合基金 | 无法使用衍生品时，通过集合基金投资可能合理。 |
