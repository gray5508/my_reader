# 术语表

这是伴读工作词表，释义为助手概括。英文含义初步核对自本地序言（PDF 物理页 18–20）及作者 Glossary（518–525）；中文是本项目暂定用词，不冒称全部来自既有译本。随逐章阅读修订，必要时记录对应中文 EPUB 位置。

不需要现在背诵。每轮只查看本段涉及的词。

| 英文 | 本项目暂定译法 | 阅读时如何区分 | 本地英文位置 |
| --- | --- | --- | --- |
| fragile / fragility | 脆弱 / 脆弱性 | 对所讨论的扰动容易受损；须说明指标和情境 | 序言 18–19 |
| robust / robustness | 稳健 / 稳健性 | 能承受扰动、表现基本不变；不能替换为反脆弱 | 序言 18；Glossary 518 |
| resilient / resilience | 有韧性的 / 韧性 | 通常强调抵御或恢复；本书序言将其与反脆弱区分，具体按句境翻译 | 序言 18 |
| antifragile / antifragility | 反脆弱的 / 反脆弱性 | 从某类波动或冲击中改善；不是对一切破坏免疫 | 序言 18–19 |
| stressor | 压力源 / 应激因素 | 指造成应激的因素，不一概译成心理压力 | 序言 18 |
| fundamental asymmetry | 基本不对称性 | 作者强调某种情境下潜在获益与损失不对称 | Glossary 518 |
| optionality / rational optionality | 可选择性 / 理性的可选择性 | 保留根据新信息改变行动的空间；具体金融语境中的 option 再译作期权 | Glossary 523 |
| barbell strategy | 杠铃策略 | 将两端组合的结构；不能读成所有问题都适用的固定比例 | Glossary 519 |
| iatrogenics | 医源性损害 | 医疗干预造成的伤害；扩展到其他领域时明确说“干预造成的损害” | Glossary 519 |
| naive interventionism | 天真干预主义 | 作者指忽略干预副作用、偏好“做点什么”的倾向；不等于一切干预无效 | Glossary 521 |
| via negativa | 否定法（通过减除） | 行动层面着重避免或移除有害因素；不是消极否定一切 | Glossary 524 |
| skin in the game | 切身利害（亲自承担后果） | 关乎承担判断与行动的代价，不能仅译成热情投入 | Glossary 522 |
| convexity / concavity | 凸性 / 凹性 | 描述反应关系的形状，必须核对横纵轴与函数；不把“凸性好”脱离原语境 | Glossary 525；第 18–19 章待精读 |
| fragilista | 脆弱推手 | 作者对自以为理解系统却增加其脆弱性的人的称呼，保留评价性 | Glossary 518；中文第 9 章标题 |
| Lindy effect | 林迪效应 | 作者关于非易逝事物的存续时间判断；不直接套用于人的剩余寿命 | Glossary 524 |
| overcompensation | 过度补偿 | 系统受刺激后建立超过上次需要的额外能力；必须保留生存阈值和生物上限 | 第 2 章 61–68 |
| redundancy | 冗余 / 额外容量 | 平时看似闲置的备用资源或能力；作者强调它既可防守也可提供机会，不等于任何库存都有效率 | 第 2 章 64–66 |
| Lucretius problem | 卢克莱修问题 | 把历史上见过的最大值误当成未来可能值的上限 | 第 2 章 65–66 |
| disfluency | 不流畅（效应） | 轻微理解阻力可能提高注意与分析投入；存在强度上限，不译成“越难懂越好” | 第 2 章 63–64 |
