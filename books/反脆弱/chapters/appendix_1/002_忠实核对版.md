## 胖子托尼的“不是同一回事”的技术版：事件与对事件的敞口混为一谈

本节也解释“凸性转化”。令 **f(x)** 表示对变量 **x** 的敞口。它也可以称作“由 x 得到的收益”“对 x 的敞口”，甚至在 f 中加入效用函数后称作“由 x 带来的收益的效用”。x 可以是任何东西。

例如：x 是某地区按某尺度衡量的地震强度，f(x) 是因此死亡的人数。让人避开某些地区、按标准建造建筑等，可使 f(x) 比 x 更可预测。例如：x 是有人把我从 x 米高处推下时的坠落米数，f(x) 是坠落对我身体状况的影响程度。显然我无法预测 x——谁会推我，作者原句在这里将 x 与 f(x) 的指代写得不很清楚。例如：x 是明天中午纽约市的汽车数量，f(x) 是某人从 A 到 B 的出行时间。坐地铁或更好地步行，可以让 f(x) 比 x 更可预测。

有些人在谈 f(x)，却以为自己在谈 x。这就是把事件与对事件的敞口混同。作者说，这个错误在亚里士多德那里已有，在概率哲学中几乎无处不在，例如哈金的论述。不理解 x，也可通过让 f(x) 呈凸形而对 x 具有反脆弱性。

面对“在一个我不理解的世界里该怎么办”，答案就是处理 f(x) 的不利状态。修改 f(x) 往往比增进对 x 的认识容易；换言之，让自己更稳健，而不是预测黑天鹅。

例如：作者说，若在市场上买保险，x 是市场跌幅超过20%；保险会使 f(x) 不再取决于 x 的概率分布中跌幅超过20%的那一段，也不受其尺度参数变化影响。这是杠铃的一个例子。此处成立须取决于保险合同、赔付能力及覆盖范围，原句是结构示意。

![图27：凸性转化](reader-web/public/antifragile/appendix_1/figure-14.jpg)

**图27。** 凸性转化，即 f(x) 是 x 的凸函数。图比较 x 本身与对 x 的敞口；第二图没有下行风险。关键是修改 f(x)，尽可能让分布左侧的 x 具有什么性质变得无关紧要。作者把这种操作称为凸性转化，在此昵称为“杠铃”。

“绿色木材谬误”也可以说成：把 f(x) 误当作具有不同非线性特征的另一个函数 g(x)。

更技术地说：若一个人对 x 具有反脆弱性，那么 x 的方差、波动率或其他变动尺度会使 f(x) 受益，因为偏斜分布的均值依赖方差；若向右偏斜，期望值随方差增大而升高。比如，对数正态分布的均值表达式包含 `+½σ²` 这一项。并且 f(x) 的概率分布，尤其在存在非线性时，与 x 的分布显著不同。

作者接着写：f(x) 单调地为凸（凹）时，f(x) 的分布右偏（左偏）；f(x) 若递增、左侧凸而右侧凹，其分布的尾部比 x 的分布更薄。他以卡尼曼—特沃斯基前景理论为例，称财富变化的“效用”比财富本身更稳健。这些概括取决于 x 的分布与函数定义，不宜脱离假设当作普遍数学定理。

**收益为何比概率更重要（技术版）。** 若 p(x) 是密度，期望值为 `∫ f(x)p(x)dx`。作者认为，f 越非线性，期望值越依赖 f 的形状，而不是 p 的细节。

## 第四象限（塔勒布，2009）

作者的想法是：在厚尾领域，尾部事件无法计算，但我们能够评估自己面对该问题的敞口。假定 f(x) 递增，表10把这个想法与“第四象限”联系起来。原书提供放大表的链接，表10在 EPUB 中为以下两张连续图片：

![表10切片1](reader-web/public/antifragile/appendix_1/figure-15.jpg)
![表10切片2](reader-web/public/antifragile/appendix_1/figure-16.jpg)

**表10｜图中文字转写。**

| f(x) 的形状 | x 为薄尾分布 | x 为厚尾分布 |
| --- | --- | --- |
| f(x) 通过截断极端结果来“减轻”影响，即先凸后凹 | 非常稳健的结果 | 相当稳健的结果 |
| f(x) 先凹后凸，放大遥远的结果 | 某种程度上稳健 | 第四象限：若 f(x) 为凹则脆弱，或为反脆弱 |

表末格的英文原图用“若 f(x) 为凹”限定脆弱一项，另一可能写作“或反脆弱”；不要把整个第四象限无条件等同于脆弱。

## 局部与整体的凸性（技术）

自然界没有什么东西无界延伸：对于一个个体，死亡就是最大的不利结果。因此，事物常在一端凸、另一端凹。生物事项存在某个最大伤害。重看第18章石头与小石子的凹形图：把观察范围扩宽，由于伤害有界，曲线总会在某处显出凸性。原先的凹性占主导，但只是局部的。图28把那个故事继续画下去。

![图28：扩大范围后的曲线](reader-web/public/antifragile/appendix_1/figure-17.jpg)

**图28。** 上图把第18章石头与小石子的讨论延至更宽范围：碰到最大伤害时，凹形在某处转为凸形。下图为强反脆弱性，没有已知上限，通向“极端斯坦”。作者说，这类收益只见于经济变量（如图书销量）或无界、近乎无界的事项；他在自然界中找不到这种效果。

**图29。** 弱反脆弱性，属于“平均斯坦”，最大结果有上限；在自然界很典型。
