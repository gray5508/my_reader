## 普罗米修斯与厄庇墨透斯

希腊传说里有两位泰坦兄弟，普罗米修斯和厄庇墨透斯。前者的名字意为“事先思考者”，后者意为“事后思考者”；厄庇墨透斯好比事后把理论套回已经发生之事、被回顾性扭曲骗住的人。普罗米修斯把火带给我们，代表文明进步；厄庇墨透斯则代表倒着思考、陈腐和不聪明。接受潘多拉礼物——那只大罐子，并引发不可逆后果的，正是厄庇墨透斯。

可选择性属于普罗米修斯，叙述故事属于厄庇墨透斯：前者允许可逆且伤害轻微的错误，后者象征打开潘多拉盒子后果的严重与不可逆。

你靠机会主义和可选择性向未来探路。到第四卷此处，我们已看到，可选择性作为另一种行动方式的力量：趁机会行动，借助不对称性取得巨大优势——收益大，伤害轻。它是一种办法，甚至是唯一的办法：驯服不确定性，在不了解未来时仍理性行动。依赖叙述则恰好相反：人反过来受不确定性驯服，甚至因此倒退。不能天真地把过去投射到未来，便以为看到了未来。

这把我们带到做与想的差别。从知识分子的立足点，理解这一点并不容易。约吉·贝拉说过：“理论上，理论与实践没有差别；实践中却有。”到这里，我们已经看到一些论证：智识活动与脆弱性相连，灌输的方法也可能与动手修补冲突；选择权则体现反脆弱性。我们把知识分成两类：形式化的一类，和胖子托尼式的一类。后者深植于试错的反脆弱性，以及下行较小、按杠铃方式承担风险——一种去智识化的冒险，或者说，它自有其智识。在不透明的世界里，作者认为这是唯一能走的路。

### 表 4｜叙述性知识与由选择权驱动的反脆弱式试错

| 叙述性知识 | 反脆弱式试错、选择权驱动 |
| --- | --- |
| 厌恶不确定性；对变化脆弱，或像火鸡那样误解过去 | 驯服不确定性；面对未知可从中受益 |
| 回看过去，容易对过去过度拟合 | 面向未来 |
| 厄庇墨透斯 | 普罗米修斯 |
| 目标预先设定的行动 | 伺机而动的行动 |
| 观光客式 | 漫游者式 |
| 脆弱、天真的理性 | 稳健的理性 |
| 心理上舒适 | 心理上不舒适，却有惊险与冒险感 |
| 凹性：眼前可见的已知收益，尚未显现的错误 | 凸性：小而已知的错误，可能很大的收益 |
| 易受火鸡问题影响，把“没有证据”误当“证据表明没有” | 可以从容易上当的人和火鸡问题中获益 |
| 易受伴随现象和绿木材谬误影响 | 躲开绿木材谬误 |
| 在实验室与物理科学之外，是学院界唯一依赖的机制 | 是实践的主要机制 |
| 把叙述当作认识依据 | 把叙述当作行动工具 |
| 被故事困住 | 不实质依赖故事；故事也可以只用来激励行动 |
| 领域狭窄，行动空间封闭 | 领域宽广，行动空间开放 |
| 需要理解事物的内在逻辑 | 无须理解太多，只需理性比较两种结果，行使较好的选择权 |
| 无法受益于“哲人石”（即凸性偏差，见第 19 章） | 依靠“哲人石” |
