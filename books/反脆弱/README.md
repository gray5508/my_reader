## 一轮阅读的样子

1. **读前**：首次进入该章时给背景、2 个观察点，最多 1 个可选问题。不用等答题才读。
2. **读中**：按原文顺序给完整顺译；难句展示“英文短句 → 直译 → 顺译”，说明影响理解的词义或句法差异。
3. **读后**：简短分开“作者主张”“论据及限制”“可质疑之处”，最多问你 1 个问题。还在论述中途时不抢做整章结论。
4. **保存**：译文和源位置写入项目并可同步到仓库；你的真实回应另存为本地讨论，结束时留下接续点。

可以随时调整：

- “只顺读，不提问”：照常保留两份译文，暂停导读和讨论。
- “切到精读”：展示全部逐句对照，缩短每批范围。
- “切到省量模式”：从下一批起只产出完整自然译文；难句才补直译，减少重复输出。
- “核对中文版”：只比较本段对应内容，标明一致、差异和定位不确定处。
- “不剧透后面”：只使用已读部分；全书地图也可暂不打开。
- “收尾”：保存已交付位置和未解决问题，不自动开启下一段。

## 为什么这样设计

《反脆弱》的难处不只是英文长句。作者使用故事、类比、讽刺和跨领域论断，读顺之后仍需要辨别论证是否成立。因此，润色只改善表达，不能替作者加强论据；讨论也不预设作者一定正确。

先试序言的一小段，再按你的反馈调整问题密度、译文风格和每批长度。文件结构服务阅读，不要求你手工填表。
