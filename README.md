# 我的本地伴读书架

按每本书自己的规则阅读原文、翻译或伴读，并通过讨论形成自己的判断。中文原书可以直接保留原文，不需要翻译。

英文原版译读：**[《反脆弱》入口](books/反脆弱/README.md)**、**[《思考，快与慢》阅读规则](books/思考，快与慢/00_阅读规则.md)**。

原文阅读伴读：**[《人生财富靠康波》入口](books/人生财富靠康波/README.md)**。阅读器书架已收录第 1—18 篇伴读；用户实际阅读进度另行记录。

精选原文伴读：**[《毛泽东选集》入口](books/毛泽东选集/README.md)**。七卷 387 篇已建[全篇索引](books/毛泽东选集/全篇索引.md)，目前开放 32 篇的伴读、易读版和原文版，分为五个可筛选的主题组；其余 355 篇保留灰色目录，待后续逐篇完善。

在这个项目里直接指定书和篇章，例如：

> 开始《反脆弱》的序言，先读一小段。
>
> 伴读《人生财富靠康波》第 7 篇，直接用中文原文。

之后可以说“继续”“这段展示逐句对照”“这里和中文版有什么差别”“我不同意作者这个例子”或“今天读到这里”。“继续”会按当前书的进度衔接；切换书时说出书名即可。无需每次重发提示词。

## 护眼阅读器

直接双击项目根目录的 **`打开阅读器.html`**，即可在浏览器中离线阅读。不需要启动服务，也不需要安装软件。首次打开先在书架选择书籍；之后打开会回到上次阅读的章节和位置。左侧目录只显示当前书籍的章节，点击顶部“书架”可换书。阅读设置支持多种背景主题、自选背景色、字号、行距和正文宽度。请让它与 `reader-data/` 保持在同一项目目录中。

阅读器界面与章节内容已经分离：`打开阅读器.html` 是固定外壳，`reader-data/library.js` 是由章节 Markdown 自动生成的数据。新增或修改章节内容后，只同步数据：

```powershell
cd reader-web
npm run sync:reader
```

只有修改阅读器界面或加载机制时才运行 `npm run build:offline`。离线页面的界面源码位于 `reader-web/offline-reader.html` 和 `reader-web/offline-reader.js`；`reader-web/` 仍保留开发版网站，日常阅读不需要运行它。

## 手机联网阅读

GitHub Pages 入口：[在线阅读器](https://gray5508.github.io/my_reader/)。手机浏览器打开即可阅读；阅读位置和外观设置分别保存在各设备的浏览器中。

每次向 `main` 推送后，`.github/workflows/reader-pages.yml` 会重新汇集章节内容并发布阅读器。发布产物包含阅读器页面、由章节 Markdown 汇集的阅读数据和 `reader-web/public/` 中的章节图片，不含 `ebook/`、个人讨论或进度文件。这个 Pages 站点对所有知道网址的人公开。

## 项目结构

```text
AGENTS.md                   全书架通用约定
books/<书名>/AGENTS.md       该书的简短特化规则
books/<书名>/00_阅读规则.md  该书的详细流程和产物约定
books/<书名>/sources/        书源版本与原文定位
books/<书名>/chapters/       章节入口和阅读内容
books/<书名>/state/          助手处理与用户阅读进度
ebook/                      原始电子书
scripts/                    本地书籍索引与片段读取
reader-web/                 本地护眼阅读器
reader-data/                自动生成的离线阅读数据
```

这是可以直接在当前对话使用的文件式伴读系统，不依赖额外模型 API。它不在后台自动翻译；你发起一轮阅读，助手读取相应原文并保存本轮结果。

批量选篇也按**一篇一篇**完成：读该篇全文和注释，写作或修改，核对质量，记录本篇进度后再进入下一篇。长任务在上下文占用约 60% 时从篇目边界另开项目会话，并用 `state/` 的逐篇记录交接；若环境不提供准确占比，提前交接，不虚报百分比。项目通用约定见 [AGENTS.md](AGENTS.md)。

Git 远程：`origin` → `https://github.com/gray5508/my_reader.git`。书源和章节内容均可纳入仓库；提取缓存、临时文件和个人讨论记录仍由 `.gitignore` 排除。

## 书籍类型如何调整

| 类型 | 主体体验 | 默认讨论重点 |
| --- | --- | --- |
| 工具书 | 操作步骤、适用条件、小规模练习 | 能否复现？成本和失败条件是什么？ |
| 思想论述类，如《反脆弱》 | 流畅译文、论证结构、概念辨析 | 证据支持到哪里？有哪些反例？ |
| 经典文学 | 保留语气、叙述视角与意象 | 人物处境、语言效果；解释可选 |
| 网络小说 | 顺畅连读、人物关系、伏笔记录 | 默认少提问、不剧透、不强加现实应用 |

新增书籍时，在实际开始伴读或翻译前，先确认原书语言、版本、目录、用户想读的方式和可读取的书源，再建立该书目录、`AGENTS.md` 与 `00_阅读规则.md`。前者只写本书要点和文件入口，后者写具体流程；不需要复制另一册的规则。中文原书可直接做“原文版＋伴读／易读版”，若用户只想读原文，就不额外生成译文或解说。已有的三本书均按此分层；原有章节文件和进度位置保持不变。
