# 我的本地伴读书架

从英文原文读懂一本书，再用自然中文读顺它，并通过少量讨论形成自己的判断。

当前书籍：**[《反脆弱》伴读入口](books/反脆弱/README.md)**。

在这个项目里直接说：

> 开始《反脆弱》的序言，先读一小段。

之后可以说“继续”“这段展示逐句对照”“这里和中文版有什么差别”“我不同意作者这个例子”或“今天读到这里”。无需每次重发提示词。

## 护眼阅读器

直接双击项目根目录的 **`打开阅读器.html`**，即可在浏览器中离线阅读。不需要启动服务，也不需要安装软件。首次打开先在书架选择书籍；之后打开会回到上次阅读的章节和位置。左侧目录只显示当前书籍的章节，点击顶部“书架”可换书。阅读设置支持多种背景主题、自选背景色、字号、行距和正文宽度。请让它与 `reader-data/` 保持在同一项目目录中。

阅读器界面与译文内容已经分离：`打开阅读器.html` 是固定外壳，`reader-data/library.js` 是由章节 Markdown 自动生成的数据。新增或修改译文后，只同步数据：

```powershell
cd reader-web
npm run sync:reader
```

只有修改阅读器界面或加载机制时才运行 `npm run build:offline`。离线页面的界面源码位于 `reader-web/offline-reader.html` 和 `reader-web/offline-reader.js`；`reader-web/` 仍保留开发版网站，日常阅读不需要运行它。

## 项目结构

```text
ebook/                 原始电子书（随仓库保存）
books/反脆弱/           规则、导览、术语、章节、讨论和进度
scripts/               本地书籍索引与片段读取
reader-web/             本地护眼阅读器
reader-data/            自动生成的离线阅读数据
AGENTS.md              助手进入本项目时的工作约定
```

这是可以直接在当前对话使用的文件式伴读系统，不依赖额外模型 API。它不在后台自动翻译；你发起一轮阅读，助手读取相应原文并保存本轮结果。

Git 远程：`origin` → `https://github.com/gray5508/my_reader.git`。书源和后续译文均可纳入仓库；提取缓存、临时文件和个人讨论记录仍由 `.gitignore` 排除。

## 书籍类型如何调整

| 类型 | 主体体验 | 默认讨论重点 |
| --- | --- | --- |
| 工具书 | 操作步骤、适用条件、小规模练习 | 能否复现？成本和失败条件是什么？ |
| 思想论述类，如《反脆弱》 | 流畅译文、论证结构、概念辨析 | 证据支持到哪里？有哪些反例？ |
| 经典文学 | 保留语气、叙述视角与意象 | 人物处境、语言效果；解释可选 |
| 网络小说 | 顺畅连读、人物关系、伏笔记录 | 默认少提问、不剧透、不强加现实应用 |

新增书籍时另建目录和自己的阅读规则；不要把《反脆弱》的论证检查模板强加给每一本书。
